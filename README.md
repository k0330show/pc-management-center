# PC Management Center — v0.11

PC内のストレージ情報を、余計な判定を加えずに「見やすく、比較しやすく、辿りやすく」表示するための試作です。

## ダウンロード

- **最新版 v0.11**: [Releases の v0.11](https://github.com/k0330show/pc-management-center/releases/tag/v0.11) から
  インストーラー `PCManagementCenter_Setup_0.11.exe` をダウンロードして実行します（GitHub の添付ファイル名は英字になります）。
- 対応: Windows 10 / 11（64 ビット）。管理者権限は不要で、使っているユーザーにだけインストールされます。Python は不要です。
- 紹介ページ: https://k0330show.github.io/pc-management-center/

> **English**: PC Management Center is a Windows app that shows what is using your disk space — a size map,
> folder and file lists with the estimated type, related app/project and the reasons — so you can check files
> before moving them to the Recycle Bin. It also finds exact duplicates, moves checked items in bulk after a
> confirmation, restores items it moved from the Recycle Bin, and can be switched between Japanese and English
> (Settings → Language). It never deletes files permanently. Download the installer from the
> [v0.11 release](https://github.com/k0330show/pc-management-center/releases/tag/v0.11) (Windows 10 / 11, 64-bit).

## v0.11 でできること（概要）

詳しい操作は下の各版の節にあります。確認は、一時フォルダだけを使い画面を出さない自動テスト（165 件）で行い、
ごみ箱からの復元は本物の Windows のごみ箱でテスト専用の一時ファイル・フォルダを使って確かめています。

| 機能 | 内容 |
|---|---|
| 容量マップ・一覧 | フォルダを面積で表示し、ルートから配下へたどれる（階層表示・戻る・親へ・中身の一覧）。フォルダ一覧・ファイル一覧で並べ替え・絞り込み |
| 正体の確認 | 種類・確度・関連するアプリやプロジェクト・判断の理由・整理する際の注意を詳細画面に表示（推定を含む） |
| 重複ファイル | 中身が完全に一致するファイルの組を検出（中身全体のハッシュで確定）。効き目の大きい組から途中結果を表示。低リスク候補・すべて・個別のチェック、2 段階の確認でまとめてごみ箱へ |
| チェックでまとめて移動 | ファイル一覧・フォルダ一覧で「移動」にチェックし、全件・件数・容量を確認してからまとめてごみ箱へ。フォルダと中身の二重処理はしない。見えていないチェック済みの項目は確認画面で件数を表示 |
| ごみ箱から復元 | このアプリが移した項目を記録し、元の場所へ戻す。同名があれば上書きしない・元のフォルダが無ければ別の場所へ戻さない |
| 日本語 / English | 初回起動時に選択。あとから「設定 → 言語」で切り替え |

完全削除・自動削除はしません。操作はすべて「ごみ箱へ移動」で、ごみ箱から元に戻せます。

大きなファイルを見つけるだけでなく、「何のデータか」「関連するデータはどれか」「削除すると何に影響しうるか」を判断する材料を表示します。ファイルは「ごみ箱へ移動」でのみ整理でき、**完全削除・自動削除は行いません。**

### 詳細画面の開き方

| 画面 | 操作 |
|---|---|
| 容量マップ | 四角を右クリック →「詳細を表示」／右上の「詳細を表示」（表示中のフォルダ） |
| フォルダ一覧 | 行をダブルクリック／Enter／右クリック →「詳細を表示」／右上の「詳細を表示」 |
| ファイル一覧 | 行をダブルクリック／Enter／右クリック →「詳細を表示」／右上の「詳細を表示」 |

エクスプローラーはどの画面でも「エクスプローラーで開く」（右クリックメニュー・詳細画面）から開けます。

詳細画面は、名前と要点（容量・更新日時・拡張子）とフルパスの下に、「これは何か」（種類・確度・用途・関連・形式・保存場所。フォルダは中身の内訳も）→「なぜそう判断したか」→「整理する際の注意」の順で表示します。

### 詳細画面からの絞り込み

「同じ種類を表示」「同じアプリ・プロジェクトを表示」「同じフォルダを表示」を押すとファイル一覧が絞り込まれます。条件は一覧の上部にボタンとして表示され、✕で個別に、「すべて解除」でまとめて外せます。条件は重ねて使えます。

### ファイル一覧の常設絞り込み

詳細画面を開かなくても、ファイル一覧の上で直接絞り込めます。条件はすべて AND で組み合わさります。

- **検索**: ファイル名またはパスに含まれる文字。
- **種類**: `classifier.py` の分類から選択。各選択肢には、ほかの条件（位置・文字）で絞った範囲での件数が表示されます。
- **位置**: スキャン済みのフォルダの配下に絞ります。次のどれでも指定できます。
  - 候補（スキャン対象と直下のフォルダ、容量順）から選ぶ
  - パスを入力して Enter（絶対パス、またはスキャン対象からの相対パス。大文字小文字は区別しません）
  - 「階層から選ぶ…」でフォルダ階層（容量・ファイル数つき）から選ぶ
  - 「直下のみ」にチェックすると、サブフォルダを含めません。

現在の条件・該当件数・合計容量は一覧の上に表示され、各条件の ✕ で個別に、「すべて解除」でまとめて外せます。詳細画面の「同じ種類を表示」「同じフォルダを表示」で設定した条件も、種類欄・位置欄にそのまま反映されるので、そこから変更・解除できます。

### ごみ箱へ移動（ファイル・フォルダ）

どの画面でも操作名は「ごみ箱へ移動」です。完全削除・自動削除は行いません。

| 画面 | 操作 |
|---|---|
| 容量マップ | フォルダの四角を右クリック →「ごみ箱へ移動」 |
| フォルダ一覧 | 右上の「ごみ箱へ移動」／右クリック／Delete キー |
| ファイル一覧 | 右上の「ごみ箱へ移動」／右クリック／Delete キー |
| 詳細画面（ファイル・フォルダ） | 下部の「ごみ箱へ移動」 |

1. 確認画面に名前・フルパスを表示します。ファイルは容量・更新日時・種類、フォルダは「中身ごと（フォルダ全体）の移動」であることと、スキャン時点と現在（数え直した値）のファイル数・サブフォルダ数・合計容量を表示します。
2. 「移動する」を押したときだけ移動します（キャンセル・Esc・Enter〔既定〕では何も変更しません）。Windows・アプリ・ゲーム・開発の管理データなどに関わる可能性がある場合や、スキャン後に中身が変わっている場合は、確認のチェックを入れるまで「移動する」を押せません。
3. 実行直前にもう一度状態を確かめ、スキャン後（または確認中）に消えた・変わった場合は移動しません。
4. 次の場所は操作対象にしません: スキャン対象のルート（とその親）、ドライブのルート、Windows・Program Files・ProgramData とその中、ユーザーフォルダ本体と標準フォルダ（デスクトップ・ドキュメント・ダウンロード・AppData など。中にあるファイル・フォルダは可）、$Recycle.Bin などのシステム用フォルダ、pagefile.sys などのシステムファイル、このアプリのインストール先、リンク（ジャンクション）のフォルダ。
5. ごみ箱のないドライブ・ごみ箱を使わない設定・ごみ箱の容量上限を超える対象は、完全削除になるため移動しません。失敗した場合は理由を表示し、表示もファイルも変えません。
6. 成功後は容量マップ・フォルダ一覧・ファイル一覧・件数・容量・絞り込み・開いている詳細画面を更新します（消えたフォルダを指す「位置」の絞り込みは外します）。元に戻すときは Windows のごみ箱から復元してください。

### 分類の方法（classifier.py）

拡張子だけで決めず、既知のファイル名、パス（Program Files / AppData / steamapps\common など）、親フォルダ名（node_modules / .git / Cache / saves など）、同じフォルダにあるファイル（package.json / UnityPlayer.dll / 同名の .cue など）を組み合わせます。

- 分類: 動画・画像・音声・文書・圧縮ファイル・インストーラー・ディスクイメージ・仮想ディスク・プログラム・ゲーム関連・セーブデータ（推定）・ソースコード・開発の依存パッケージ／生成物・開発の変更履歴・設定・ログ・キャッシュ・データベース・フォント・3D/デザイン・バックアップ・システムファイル
- 関連先: Steam / Epic / GOG / Riot / Xbox のゲーム、Unity・Unreal 製ゲーム（部品から推定）、開発プロジェクト（Node.js / Python / .NET / Unity など）、AppData・Program Files・ProgramData のアプリ、Windows
- `.dat` `.bin` や拡張子なしなど中身を特定できないファイルは「種類は不明」とし、「保存場所から○○の可能性」とだけ表示します。

分類はスキャン時に一度だけ行い、詳細画面・絞り込みはその結果を使います（ディスクを再スキャンしません）。一覧は全件を絞り込み・並べ替えしたうえで上位 2,000 件（フォルダは 3,000 件）だけを描画します。

## v0.6 で追加: 重複を確かめる・中身を辿る・まとめて片づける

### 1. 重複ファイルを探す（押したときだけ）

「重複ファイル」タブの **「重複ファイルを探す」** を押したときだけ動きます。
通常の容量スキャンは今までどおりで、重複の確認は一切しません。

**中身が 1 バイトも違わないものだけ**を重複とします。名前が同じでも中身が違えば
別物として扱い、名前が違っても中身が同じなら同じ組に入れます。

読む量は三段で絞ります。

1. 容量が同じもの同士だけを候補にする（容量が違えば中身も違う）
2. 先頭と末尾の 64KB だけ読んで、そこで違えば落とす
3. 残ったものだけ全体を読んで突き合わせる

**候補にしないもの**（理由つきで件数を表示します）。

| 種類 | 理由 |
|---|---|
| シンボリックリンク・ジャンクション | 実体は別にあり、数えると同じ中身を二度数えることになる |
| ハードリンク（同じ実体を指す別名） | 消しても容量は空かない |
| クラウドにのみ実体があるファイル | 読むと OneDrive などが実体を取りに行く（大量ダウンロード） |
| 空ファイル | 消しても容量は空かない |
| 読み取れなかった・検出中に消えたファイル | **「重複なし」とは判断しません**。件数を別に出します |

**「見かけの合計」と「空く容量」を分けて表示します。** 見かけの合計は同じ中身を
何度も数えた値で、これだけ空くわけではありません。空くのは各組で 1 本残した残りです。

**「調べる大きさ」**（既定は「すべて」）で、小さいファイルを省けます。時間のほとんどは
ファイルを開く回数で決まるため、ここが効きます（実測は「所要時間」の節）。
省いた分は「◯◯未満のファイルは調べていません」と画面に出ます。

検出中は「どこまで調べたか」と「ここまでに何組見つかり、どれだけ空きそうか」を
表示します。**中止**でいつでも止められ、そこまでの結果が残ります。

### 2. 重複結果から整理する

**どれを残すかはユーザーが選びます。** アプリは「古い方が不要」などと決めません。

1. 残したい行を選んで **「これを残す」**。◉ が付きます。もう一度押すと外れます。
2. 移したい行を選んで **「ごみ箱へ移動」**（Delete キーでも可）。複数をまとめて移すときは v0.7 の「チェック」を使います。
3. 確認画面には、移すファイルに加えて **残すファイルの名前と場所**、その組で空く容量を出します。
4. 移す直前に、**残す側と移す側の両方**が検出後に変わっていないかを確かめます。
   どちらかが変わっていれば移動しません。
5. （v0.7 で変更）残す側を選んでいない組では、アプリが残す側の **案（◎）** を置き、確認画面に
   「アプリが選んだ案」と明記して出します。案のまま移したくなければ、キャンセルして「これを残す」で選び直せます。

既存の保護対象・確認画面・ごみ箱への移動条件はそのまま適用されます。
完全削除・一括自動削除は追加していません。

移動に成功すると、重複結果・ファイル一覧・フォルダ容量・容量マップ・絞り込み件数を
まとめて更新します。組が 1 本だけになったら、その組は一覧から消えます。

### 3. フォルダの中身を辿る

「フォルダ一覧」が階層表示になりました。行の **▶** を押すと、その直下のフォルダと
ファイルが出ます（開いた所だけ読み込みます。全階層を先に広げると数万行になるため）。

- 上部に **今見ている場所** と **← 親フォルダ** を表示します。
- 中身のファイル・フォルダから、**詳細を表示**・**エクスプローラーで開く**・
  **ごみ箱へ移動**・**ファイル一覧でこの場所を見る** へ進めます（右クリック）。
- 中身の数字は**スキャン結果から作ります**（ディスクを読み直しません）。容量マップ・
  ファイル一覧・位置の絞り込みと同じ値になります。
- 容量マップで場所を開いたときと、詳細画面の「同じフォルダを表示」を押したときは、
  フォルダ一覧でも**同じ場所が開きます**（別の操作で開いて表示が食い違うことはありません）。
- 中身を辿れるようにしても、**守っている場所は操作できません**。保護の判定はパスで
  決まるので、どの画面から選んでも同じに効きます（スキャン対象のルート、Windows・
  Program Files・ユーザーフォルダ本体など）。

### 4. ファイル一覧の複数選択

Windows の一覧と同じ作法です。

| 操作 | 動き |
|---|---|
| クリック | 1 件選ぶ |
| Shift + クリック / Shift + ↑↓ | 範囲で選ぶ |
| Ctrl + クリック | 1 件ずつ追加・解除 |
| Ctrl + A | 表示中の全件 |
| 右クリック（選択中の行） | **選択を崩しません**。そのままメニューが出ます |
| 右クリック（選択していない行） | その 1 行に切り替えてメニューを出します |

選択中は **件数と合計容量**を一覧の上に表示します。

- **詳細を表示**は 1 件のときだけです。複数選択のまま押すと、その旨を表示して開きません。
- **ごみ箱へ移動**は複数件に対応します。確認画面に**全件の一覧**（スクロールできます）・
  件数・合計容量を出し、保護対象と検出後に変わったものは「移動しないファイル」として
  理由つきで分けて表示します。
- 移す直前にも 1 件ずつ確かめ、**一部だけ失敗した場合は成功と失敗を分けて報告**します。

## v0.7 で追加: 重複を「まとめて選ぶ」3 通りと、2 段階の確認

重複が数万件あると 1 件ずつ選ぶのは現実的ではありません。一方、中身が同じでも、別バージョンの
プロジェクトや別のアプリがそれぞれの場所のファイルを必要としていることがあります。そこで
**選ぶ操作は 3 通り**用意し、**移す操作は 1 つの確認手順**に通します。

### 画面（重複ファイル タブ）

| 場所 | 内容 |
|---|---|
| 2 行目 | **低リスク候補を選ぶ…** ／ **すべて選ぶ ▾** ／ **チェックをすべて外す** ／ 選択中の件数・容量・範囲 ／ **チェックしたものをごみ箱へ…** |
| 一覧の上 | 絞り込み（パスの文字）・表示（すべての組／チェックのある組／チェックのない組）・ページ（◀ 前 ／ 次 ▶） |
| 一覧の列 | **移動**（☑ ☐。組の行は ☑ 全部 ／ ▣ 一部 ／ ☐ なし）・**残す**（◉ 指定 ／ ◎ アプリの案）・…・**判定**（低リスク判定の結果、前回移せなかった理由） |

一覧は 1 ページ 100 組ずつ描きます（数万組でも重くならないように）。全体への操作は、描いていない組にも効きます。

### 1. チェックしたものだけ移す（個別に選ぶ）

| 操作 | 動き |
|---|---|
| 「移動」欄をクリック | その行のチェックを切り替える（組の行なら、組の「残す」以外をまとめて） |
| 「移動」欄を Shift + クリック | 前にクリックした行からここまでを、同じ状態にそろえる |
| 行を Ctrl + クリック | 離れた行を選択に追加・解除（間の行は選ばれません） |
| 行を Shift + クリック | 範囲で選択 |
| Space | 選んでいる行のチェックを切り替える（未チェックが 1 件でもあれば全部付け、なければ全部外す） |
| Ctrl + A | このページの行をすべて選択 |
| 右クリック | 選んである行の上なら**選択を崩さず**メニューを出す |
| 「これを残す」 | その行を残す側に指定（チェックは外れます） |

**各組で最低 1 件は必ず残ります。** 組の全部にチェックを付けようとすると最後の 1 件は断ります。
チェックを付けた組に残す側が決まっていなければ、アプリが案（◎）を置きます
（コピー名でない → ダウンロード以外 → 更新日時が古い → パスが短い、の順）。
**案であって、それを残せば安全という意味ではありません。** いつでも「これを残す」で変えられます。

### 2. すべて選ぶ

「すべて選ぶ ▾」から範囲を選びます。**範囲はメニュー・画面上部の「範囲」・両方の確認画面に明記します。**

- **表示中の N 組（このページ）**
- **絞り込みに一致する全 N 組**（絞り込み中のみ）
- **検出結果の全 N 組**（表示していない組も含む）

各組の「残す」以外にチェックを付けます（今のチェックに加えます。まだ移動はしません）。

### 3. 低リスク候補を選ぶ

**「削除しても問題ない」ものを選ぶ機能ではありません。** 用途を推測できる材料がそろい、推測が外れにくい
ものだけを機械的に選び、それ以外は対象を広げずに「個別確認」に回します。次を**すべて**満たすファイルだけが候補です。

- 保存場所が ダウンロード・デスクトップ・ドキュメント・ピクチャ・ビデオ・ミュージック の中（OneDrive などの同期フォルダは除く）
- 開発プロジェクト・依存パッケージ（node_modules など）・変更履歴（.git）・アプリ／ゲームのインストール先やデータ
  （Program Files・AppData など）・Windows・キャッシュ・ログ・セーブデータ・バックアップの領域ではない
- 途中のフォルダ名に版の違いを思わせる言葉がない（v2・1.0.3・old・new・latest・release・旧・最新・版 など）
- 拡張子から 写真・動画・音楽・書類（PDF・Office など）・圧縮ファイル・インストーラー と確定できる
  （.txt .csv .html .svg .json など、プロジェクトの部品になりやすいものは入れない）
- 名前が . で始まらない

組の中に条件に合わないファイルがあれば、そちらを残し、条件に合う方だけにチェックを付けます。
利用者が「残す」に指定したファイルは尊重します。押すと、候補の件数・移動予定の容量・
除外した件数と理由（件数の多い順）・判定の限界を表示し、「候補にチェックを付ける」を押したときだけ
今のチェックと置き換えます（ここでも移動はしません）。判定結果は「判定」欄に残ります。

**判定の限界**: 材料はフォルダ名・拡張子・保存場所・フォルダ内の目印（package.json など）だけで、
ファイルの中身や、アプリ・スクリプトがどこを読みに行くかは調べていません。目印のないプロジェクトの素材や、
ツールが決まった場所で使っているファイルは見分けられません。候補に入っても、移動前の一覧で場所と残す側を確かめてください。

### 移動: 独立した 2 段階の確認

チェックが 2 件以上あるとき「チェックしたものをごみ箱へ…」（Delete キーでも可）で次の順に進みます。
1 件だけなら従来の 1 件用の確認画面です。

**確認 1/2（規模と起こりうること）** — 移動はしません。

- 件数・容量・組数、選んだ範囲（「検出結果の全 23,068 組」など）
- 主な保存場所（スキャン対象から 2 段目のフォルダごとの件数・容量）
- 対象に含まれるもの（開発プロジェクトの中 ◯件、用途を判定できない場所 ◯件 …）
- 起こりうること: 各組で 1 件は残すが、それで代わりになるとは限らないこと、別バージョンのプロジェクトや
  別のアプリがそれぞれの場所のファイルを必要としている場合があり、ビルドや起動ができなくなりうること
- **既定のボタンはキャンセル**（Enter・Esc・×で閉じると何もしません）。進むボタンは「次へ: 移動するファイルの一覧を確認する」

**確認 2/2（最終的な移動対象の一覧）** — 1 段目とは別の画面です。

- 全件を組ごとに「残す」「→ ごみ箱へ移動」「移動しない: 理由（保護対象など）」で並べます。
  100 組ずつのページで**全件をたどれます**。「一覧を保存（CSV）…」で全件を書き出して確かめることもできます。
- この画面でも「残す側にする」「移動から外す」ができ（Ctrl・Shift で複数行）、本体のチェックにも反映します。
  残す側を変えても、前の残す側が黙って移動対象に加わることはありません。
- 「一覧を確認し、上の N 件を移動すると自分で判断しました」にチェックを入れるまで
  「N 件をごみ箱へ移動」は押せません。対象が変わるとチェックは外れ、確認し直しになります。

### 実行と結果

- 実行直前に計画を作り直し、**1 件ずつ**既存の保護対象判定・スキャン後の変更／消失の確認・
  ごみ箱に入るか（完全削除にならないか）の確認をしてから移します。組の「残す」側が消えた・変わった組は移しません。
- 20 件以上なら進み具合と「中止」を出します。中止すると残りは実行しません。
- 結果は **移動した／移動しなかった（確認で止めた・失敗）／未実行** に分けて件数と理由を表示し、
  一覧・容量・件数・重複結果をまとめて更新します。移動しなかったものはチェックを外して「判定」欄に理由を出し、
  未実行のものはチェックを残します（そのまま続きを実行できます）。
- 完全削除・確認なしの自動移動はありません。元に戻すときは Windows のごみ箱から復元してください。

### フォルダ一覧・ファイル一覧の複数選択

- フォルダ一覧も **Ctrl + クリック（離れた行）・Shift + クリック（範囲）** で複数選べます。
  選択中の件数・合計容量（フォルダは中身ごと）を上に表示し、右クリックは選んである行の上なら選択を崩しません。
- 複数選んで「ごみ箱へ移動」すると、フォルダとファイルを 1 つの確認画面に全件出します。フォルダの中にある行も
  選んでいた場合は、フォルダと一緒に移るので二重に数えません（ただし守っている場所のフォルダの中の行は外しません）。
- まとめて移すときは、守っている場所・リンク、**スキャン後に中身が変わったフォルダ**、読み取れない項目のある
  フォルダは移しません（1 件ずつ確認して移してください）。確認画面を開いている間に中身が変わったフォルダも移しません。
- ファイル一覧は v0.6 と同じ作法です（Ctrl + A・右クリックで選択を崩さない・確認画面に全件）。

## v0.8 で追加: 速い重複検出・たどれる容量マップ・一覧のチェック・ごみ箱から復元

### 1. 重複ファイル検出を速くした

実データ（Downloads・121,607 ファイル・候補 113,410 件）で工程ごとに測ると、時間のほとんどは
**ファイルを開いて先頭・末尾を読む**工程でした（旧版 737 秒のうち 690 秒。候補の抽出 0.04 秒、
全体のハッシュ 3.4 秒、結果の表示 0.03 秒）。そこで次のように変えました。

- リンク・クラウドのみのファイルは、スキャン時に得た属性で**開く前に**外す
- 1 ファイルは **1 回だけ開く**（旧版は lstat と読み込みで 2 回開いていた。別名＝ハードリンクの確認も同じハンドルで）
- 開く・読むを**複数スレッドで重ねる**（待ち時間が主で CPU はほとんど使わない。大きいファイルの全体読みは 2 本まで）
- 進捗の計算を足し込み式にした（旧版は組が増えるほど進捗の計算が重くなっていた）

**組にするのは中身全体の要約（BLAKE2b-256）が一致したものだけ**です。先頭・末尾だけの一致では組にしません
（小さいファイルは先頭・末尾の読み込みで全体を読み切っています）。

| 同じファイル集合での実測 | 旧版（v0.7） | 新版（v0.8） | 結果 |
|---|---|---|---|
| Downloads・キャッシュが冷えた状態 | 737 秒 | 測れず（※） | — |
| Downloads・キャッシュが効いた状態 | 64.1 秒 | 12.95 秒 ／ 14.65 秒 | 23,068 組・完全に一致 |
| 合成データ 27,036 ファイル・3 GB | 7.0 〜 7.3 秒 | 4.2 〜 4.35 秒 | 7,211 組・完全に一致 |

※ 同じ条件（OS とウイルス対策ソフトのキャッシュが空）を作るには再起動が要るため、測れていません。

**検出中の表示**: 効き目（容量 × 本数）の大きい候補から確かめ、確定した組から順に一覧へ並べます。
画面には「検出中（途中結果）」「まだ確かめていない候補が残っています。表示中の組数・容量は全体の結果ではありません」と出し、
検出中はチェック・移動はできません。**中止**したときは「中止しました（途中までの結果）」と、まだ確かめていない候補の件数を出します。
検出は別スレッドで動き、画面は固まりません。

### 2. 容量マップをたどれるようにした

- 四角をクリックでそのフォルダへ。**← 戻る**（直前の場所）・**↑ 親フォルダ**・**階層表示**（どの階層もクリックで移動。深いときは途中を … にまとめる）
- 「表示中: ◯◯ ・ 容量 ・ ファイル数 ／ 親フォルダ「◯◯」の ◯% ／ スキャン対象全体の ◯%」を上に表示
- 四角を正方形に近い形で敷き詰める方式にした（以前は帯を一方向に並べていたため、項目が多いと細い線になって選べなかった）
- 右に**この場所の中身の一覧**（容量順・割合つき・全件）。地図で小さすぎる項目もダブルクリックで開ける。地図は大きい 300 件まで描き、残りは「ほか N 件」にまとめる

### 3. ファイル一覧・フォルダ一覧でもチェックしてまとめて移す

- 両方の一覧に「移動」欄。クリックで切り替え、**Shift + クリックで範囲**、行を Ctrl／Shift で選んで **Space** でまとめて切り替え
- チェックは両方の一覧で共通。**件数・合計容量**を上に表示。「チェックしたものだけ表示」で確かめ、個別に外せる
- ファイルは項目そのもの、フォルダはパスで覚えるので、**絞り込み・並べ替えではチェックは変わらない**
- フォルダとその中の項目を両方チェックすると、中の項目は ▣（フォルダと一緒に移る）になり、**二重には処理しない**

- 一部だけ移せなかったときは**対象ごとの結果**（移動した／移動しなかった＋理由／未実行）を一覧で出し、一覧・容量マップ・件数を実際の結果に合わせる

### 4. 「ごみ箱から復元」タブ

**このアプリ（v0.8 以降）がごみ箱へ移した項目だけ**を一覧にし、選んだものを元の場所へ戻せます。
Windows のごみ箱全体は扱わず、空にする・完全に削除する機能はありません。

- 列: 状態（ごみ箱にあります／見つかりません／特定できません／復元済み）・名前・種別・容量・移動日時・元の場所。検索・表示・種別で絞り込み、Ctrl／Shift で複数選択
- 記録は `%LOCALAPPDATA%\PCManagementCenter\trash_log.json` に残るので、アプリを閉じても追える
- **特定の方法**: 移した直後にごみ箱（`<ドライブ>\$Recycle.Bin\<ユーザーの SID>`）の `$I` を読み、元のパスが一致し、移す直前以降に作られ、まだ他の記録に使っていないものが**ちょうど 1 つ**のときだけ、その組（ランダムな名前の `$R` と `$I`）を記録します。
  見つからない・2 つ以上あるときは推測せず「特定できません」。名前と元のパスだけでは同じものと決めず、確認のたびに `$I` の中身（元のパス・100 ナノ秒単位の移動日時・容量）と `$R` の有無・種類を照らし合わせます
- Windows 側で元に戻した・削除した項目は「見つかりません」になり、戻せません（「記録から外す」で一覧から外せる。ごみ箱は変えない）
- 復元の前に対象・復元先・戻せない理由と対処を確認画面に出します（既定はキャンセル）。
  **同じ名前があれば上書きしない**。**元のフォルダが無ければ別の場所へは戻さない**（元のフォルダもこの一覧にあれば「先にそれを復元」と案内し、両方選べばフォルダから順に戻す）
- 戻した後は項目ごとの結果を出し、スキャン結果が古くなったことと「もう一度スキャン」を案内します

**制約**: 特定には `$I` / `$R` の仕組み（Vista 以降、NTFS）を使います。これは Windows の公開 API ではないため、
知らない形式（版 1・2 以外）なら特定しません。v0.7 以前に移したもの・特定できなかったものは、Windows のごみ箱から戻してください。

## 配布版の作り方

1. 版を上げる場合は、`app.py` の `APP_VERSION`、`version_info.txt`、`installer.iss` の `SetupVersion` をそろえて更新する。
2. このフォルダで `python -m PyInstaller --noconfirm "PC管理センター.spec"` → `dist\PC管理センター\` に生成（exe のプロパティ > 詳細 に版が入る）。
3. このフォルダで `"C:\Program Files (x86)\Inno Setup 7\ISCC.exe" installer.iss` → `..\installer\PC管理センター_Setup_<版>.exe` に生成（版ごとに別ファイル。パスは installer.iss の置き場所からの相対パス）。
   公開するときは GitHub の Release に添付する（添付ファイル名は英字 `PCManagementCenter_Setup_<版>.exe` にする。GitHub は日本語のファイル名を「.」に置き換えるため）。
4. 生成した Setup を実行してインストールする。インストール済みの版は「設定 > アプリ > インストールされているアプリ」の「PC管理センター <版>」、または exe のプロパティで確認できる。

## 所要時間（実測）

同じ PC・同じフォルダ（`C:\Users\<user>\Downloads`、121,607 ファイル / 5,870 MB）での実測です。

| 処理 | 時間 | 備考 |
|---|---|---|
| 通常の容量スキャン | **3.5 秒** | 重複検出を足しても変わりません（別処理です） |
| 重複検出 | 下記参照 | 中身を読むため、ファイル数に比例して長くかかります |

重複検出は **ファイルを開いて読む**ぶんだけ時間がかかります。時間のほとんどは
「開く回数」で決まります（ウイルス対策ソフトが開くたびに検査するため、環境差が大きい）。
そこで **「調べる大きさ」** を選べるようにしました。同じフォルダでの実測です。

| 調べる大きさ | 時間 | 中身を確かめた数 | 見つかった組 | 空く可能性 |
|---|---|---|---|---|
| **すべて**（既定） | 737 秒（v0.7、キャッシュが冷えた状態） | 113,410 | 23,068 組 | 1,158 MB |
| 1 MB 以上 | **49 秒** | 202 | 69 組 | **692 MB** |
| 10 MB 以上 | 5.4 秒 | 14 | 4 組 | 406 MB |

1 MB 以上なら、**15 分の 1 の時間で空く容量の 6 割**が見つかります。小さいファイルは
数が多いわりに空く容量が小さく、開く回数だけが増えるためです。

既定は **「すべて」** です。1 MB 以上を既定にすると時間は 15 分の 1 になりますが、
小さいファイルばかりのフォルダで「重複なし」に見えてしまいます。このアプリは
取得できた事実だけを出すと決めているので、**黙って省きません**。時間がかかるときに、
自分で狭めてください。狭めた場合は「◯◯未満のファイルは調べていません」と画面に出ます。

効き目（空く容量）の大きい組から調べるので、**途中で中止しても価値の大きい結果から
残ります**。進捗には「ここまでに何組・どれだけ空きそうか」を出しています。

この表は v0.7 での実測です（v0.8 の比較は上の「v0.8 で追加」を参照）。
`python bench.py <フォルダ>` で、この二つの時間を自分の環境でも測れます（読むだけで、
何も移動しません）。

## 現時点の制約

- スキャンは選択フォルダ以下を再帰走査します（約 19.4 万ファイルで約 4 秒。容量・更新日時はフォルダ列挙時に OS から得た値を使います）。
- 読み取れないフォルダ、情報を取得できなかったファイル、辿らなかったリンク（シンボリックリンク・ジャンクション）、除外したフォルダ（ごみ箱など）は読み飛ばし、完了時に件数を表示します。
- スキャンのたびに全体を読み直します（前回結果のキャッシュはありません）。
- Windowsの「最終アクセス日時」は環境によって更新が抑制されることがあるため、v0.2では正確性を優先して標準表示に入れていません。
- インストーラーにはコード署名がありません。初回の実行時に Windows SmartScreen の警告が出ることがあります（「詳細情報」→「実行」で進めます）。
- 「ごみ箱から復元」で戻せるのは、v0.8 以降のこのアプリがごみ箱へ移し、ごみ箱の中の項目を特定できたものだけです。
  特定には Windows のごみ箱の内部の仕組み（`$I` / `$R`、公開 API ではない）を使っています。それ以外は Windows のごみ箱から戻してください。
- 英語表示でも、Windows 標準の画面（フォルダを選ぶ・保存する画面など）は Windows の言語で表示されます。
